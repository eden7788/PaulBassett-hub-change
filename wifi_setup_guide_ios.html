1

휴대폰에서 Wi-Fi 연결하기

먼저 아이폰을 새 Wi-Fi에 연결합니다. 위에서 복사한 이름/비밀번호를 사용하세요.

1설정 앱에서 Wi-Fi 선택

아이폰 설정 앱을 열고 Wi-Fi를 눌러주세요.

2‘기타…’ 선택

네트워크 목록 가장 아래에 있는 기타…를 눌러주세요.

숨겨진 네트워크라 목록에는 보이지 않아요. 그래서 ‘기타…’로 직접 등록해요.
3이름·비밀번호 입력 후 연결

이름란에 pbc 를 입력하면 보안은 자동으로 WPA2/WPA3로 표시돼요. 암호란에 maeil01!@ 를 입력하고, 오른쪽 위 체크(✓)를 누르면 연결이 시작돼요.

2

리프 앱에서 허브 Wi-Fi 재설정하기

휴대폰이 새 Wi-Fi에 연결된 상태에서, 리프 앱으로 허브의 Wi-Fi 정보도 같은 네트워크로 바꿔주세요.

① 기기 관리 선택 → ② Wi-Fi 재설정 선택 → ③ 허브 MAC 주소 확인 → ④ 블루투스 스캔 선택
⑤ 허브 선택 → ⑥ 허브 연결 성공 → ⑦ Wi-Fi 비밀번호 입력 (iOS 전용 화면)
⑧ 허브 Wi-Fi 정보 변경 중 → ⑨ 재설정 완료 → ⑩ 기기 관리에서 최종 확인
